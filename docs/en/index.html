How this pick is calculated

In a survivor pool a single loss eliminates you, and each team can only be used once. Taking the biggest favourite every week is therefore not the right strategy: the strong teams have to be saved for the weeks when nothing else holds up.

This site blends five sources — sportsbook odds, Kalshi, MoneyPuck, Dimers and Puckcast — into a weighted consensus, then optimises the plan over the next eight weeks at once. It maximises the expected number of weeks survived, which accounts for the fact that an early elimination cancels every week after it.

Data is collected twice a day, before and after the games.
